# notes/

Project writing that is *about* Sarathi, kept deliberately outside `docs/`.

`docs/` is the retrieval corpus — `src/ioe/rag.py` indexes every indexable file in
it, so anything dropped there becomes something the assistant will cite to a
student. Notes on how the app was built are not notices about the entrance exam,
so they live here instead.

## sarathi-ledger.html

The build narrative: twelve chapters on what was tried, what was measured, and
what replaced it. Amber marks a measured failure, teal the deterministic fix.
Open it in a browser directly — it is self-contained apart from Google Fonts.

It is the source of the published artifact
<https://claude.ai/code/artifact/2a6e8074-8496-4b05-a69a-d9ccfc7942af>.
Editing this file and re-publishing it to that URL updates the same page; the
copy here is the one that survives, since the artifact is private to one account.
