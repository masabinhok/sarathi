# Sarathi — evaluation test cases

Every check in `src/ioe/eval.py`, listed. Generated by `notes/list_tests.py` straight from the suite, so it cannot drift from what actually runs.

**71 checks** — 54 single-turn cases, 12 conversation turns across 3 threads, 5 figure checks, plus a detector precision check over 10 task requests.

The suite asserts **which evidence the application assembled** before the model wrote anything — not the prose it wrote. `evaluation.md` explains why. Two columns therefore matter equally:

- **Must assemble** — the evidence that has to be in front of the model.
- **Must not** — evidence that must be absent. This is where the subtle regressions show up: a fee question that *also* refuses is broken even though the figures arrived.

Evidence names:

| Name | Means |
| --- | --- |
| `documents` | retrieved passages |
| `lookup` | exact pass-list record |
| `fees` | worked fee totals |
| `seats` | published seat table |
| `priority` | priority-order rules |
| `chances` | 2083 allocation, simulated |
| `cutoffs` | published closing ranks |
| `notices` | live notice listings |
| `dates` | BS/AD conversions |
| `uncovered` | no source matched |
| `declined` | refused, no model call |

## Figure checks — 5 checks

The only cases that run generation. They exist because the design above has one blind spot: a block can be correct, the evidence assertion can pass, and the model can still read the wrong line out of it. Asked what the whole degree costs at Full Fee, the assistant once answered `218,070` — the admission-day total, printed on the line directly above the right one — and the suite reported success. These assert that one specific printed figure appears in the answer.

## Detector precision — 10 task requests

`scope.is_task_substitution` is the one deterministic thing between a student and "here's a simple Python function". Its danger is not missing one — it is firing on a genuine question, which is how an earlier scope guard broke conversations. So it is checked in both directions: it must catch all of these, **and stay silent on every other question in this document.**

1. write me a python function to reverse a list
2. write me a python function to calculate sum of three numbers
3. solve x^2 + 5x + 6 = 0
4. recommend a good laptop under 80000
5. who won the world cup
6. what is the capital of france
7. can you help me with my physics homework
8. translate this into nepali
9. debug my code please
10. write me an essay about nepal

## Running them

```bash
uv run python -m ioe.eval                 # everything
uv run python -m ioe.eval fees            # one group
uv run python -m ioe.eval cutoffs chances # several
uv run python -m ioe.eval figures         # only the answer-text checks
```

Exit status is the number of failures, so it is usable as a gate. The four data modules verify themselves separately — `uv run python -m ioe.fees`, `.seats`, `.cutoffs`, `.priority` — each re-deriving every published total from its line items and reporting any that disagree.
